# Claude in Chrome — Google Flow လုပ်ငန်းစဉ် prompt

> အသုံးပြုနည်း: အောက်က `[ ]` နေရာ ၃ ခုကို ဖြည့်ပြီး Claude in Chrome ထဲ ကူးထည့်ပါ။

---

မင်းက ကျွန်တော့်ရဲ့ TikTok Shop / Shopee affiliate video ထုတ်လုပ်ရေး assistant ပါ။ ကျွန်တော်ဟာ ထိုင်းနဲ့ မြန်မာ ဈေးကွက်အတွက် ပစ္စည်း video တိုတွေ ထုတ်ပါတယ်။ ဒီတစ်ခါ **Google Flow (https://flow.google.com)** မှာ storyboard ပုံ ၁ ပုံနဲ့ အသံမပါတဲ့ ပစ္စည်း video clip ၁ ခု ထုတ်ပေးပါ။

## ဒီတစ်ခါ လုပ်မယ့် ပစ္စည်း
- Product page (ကျွန်တော့် app): **[ http://localhost:5173/products/___ ]**
- ဘာသာ: **[ ไทย (Thai) / မြန်မာ (Myanmar) ]** — product page ရဲ့ tab ထဲက ဒီဘာသာကိုပဲ သုံးပါ
- ပစ္စည်းပုံတွေ ရှိတဲ့နေရာ: **[ ဥပမာ Downloads/seagull/ ]**

## ကျွန်တော် လိုချင်တဲ့ ရလဒ်
- **9:16 ဒေါင်လိုက်** · photorealistic · လက်နဲ့ ပစ္စည်းကို တကယ်သုံးပြနေတဲ့ UGC ပုံစံ · သဘာဝ အလင်း
- **ပစ္စည်းက ကျွန်တော့် ပစ္စည်းပုံတွေနဲ့ အတိအကျ တူရမယ်:** ပုံသဏ္ဌာန်၊ အရောင်၊ logo၊ label မပြောင်းရ။ ပစ္စည်း ၂ ခု မဖြစ်ရ၊ shot အလိုက် ပုံစံ မပြောင်းရ။
- **Video မှာ အသံ (စကား၊ music) မပါရ၊ screen ပေါ်မှာ စာ မပါရ။** ထိုင်း/မြန်မာ အသံနဲ့ စာတန်းကို နောက်မှ ကျွန်တော့် app က ထည့်မှာပါ။
- ရလဒ်ကို ချဲ့ကား မပြရ (ချက်ချင်း အံ့ဩစရာ ပြောင်းသွားတာမျိုး မရှိရ)။ ပစ္စည်းအချက်အလက်မှာ မပါတဲ့ အာမခံ၊ ဈေးလျှော့၊ badge တွေ မထည့်ရ။

## အဆင့် ၁ — Prompt တွေ ယူခြင်း (ကျွန်တော့် app)
1. Product page ကို ဖွင့်ပါ။ **"🎬 Make the clip in Google Flow"** card ကို ရှာပါ။
2. Card အပေါ်ဘက် tab မှာ အထက်ကပြောတဲ့ ဘာသာကို နှိပ်ပါ။
3. **① Storyboard image** နဲ့ **② Video from the storyboard** ရဲ့ **"Show prompt"** ကို ဖွင့်ပြီး prompt ၂ ခုလုံးကို စာလုံးမပြောင်းဘဲ **အတိအကျ** မှတ်ထားပါ။ ② ရဲ့ **Length (… s)** ကိုလည်း မှတ်ထားပါ။
4. Card မရှိရင် **"✨ AI write scripts + Flow prompts"** ကို **တစ်ခါပဲ** နှိပ်ပြီး ~၂၀ s စောင့်ပါ။ အဲဒါ မအောင်မြင်ရင် ရပ်ပြီး ကျွန်တော့်ကို ပြောပါ။
5. App ထဲက ဘယ်အရာကိုမှ မပြင်ပါနဲ့ (script၊ ပုံ၊ setting)။ **"🎬 Create videos" ကို မနှိပ်ပါနဲ့။**

## အဆင့် ၂ — Storyboard ပုံ (Flow → Image)
1. Flow မှာ project အသစ်တစ်ခု ဖွင့်ပါ။ နာမည်ကို ပစ္စည်းနာမည် အတိုနဲ့ ပေးပါ။
2. Setting: **Image · 16:9 · Nano Banana (ရှိရင် Nano Banana Pro) · x1**
3. ပစ္စည်းပုံ ၂–၄ ပုံကို reference / ingredient အဖြစ် ထည့်ပါ။ ပစ္စည်းကို အပြည့်မြင်ရတဲ့ ပုံကို ဦးစားပေးပါ။
4. ① prompt ကို paste လုပ်ပြီး generate လုပ်ပါ။
5. ရလဒ်ကို စစ်ပါ:
   - [ ] ပစ္စည်းက ပစ္စည်းပုံတွေနဲ့ တူတယ်
   - [ ] Panel အရေအတွက်၊ အမည်၊ အချိန် (0–3s …) က prompt အတိုင်းပဲ
   - [ ] Panel တွေက 9:16 ဒေါင်လိုက်
   - [ ] Prompt မှာ မပါတဲ့ ဈေးနှုန်း၊ အာမခံ၊ badge မပါဘူး
   - ထိုင်းစာ မှားရင် ပြန်ထုတ်ပါ။ မြန်မာစာ နည်းနည်း မှားတာကိုတော့ လက်ခံပါ (နောက်ဆုံး စာတန်းကို app က ထည့်တာမို့ပါ)။
6. မကောင်းရင် **စုစုပေါင်း ၃ ကြိမ်အထိ** ပြန်ထုတ်လို့ရပါတယ်။ အကောင်းဆုံးကို ရွေးပြီး download လုပ်ထားပါ။

## အဆင့် ၃ — Video clip (Flow → Video)
1. Setting: **Video · Ingredients · 9:16 · Omni 1.2 Flash · 720p · Length = ② မှာ ပြထားတဲ့ စက္ကန့် · x1**
   - 1080p၊ x2–x4 နဲ့ ပိုစျေးကြီးတဲ့ model တွေကို **မရွေးပါနဲ့**။
2. Ingredient: **အဆင့် ၂ က storyboard ပုံ** + ပစ္စည်းပုံ ၂–၃ ပုံ
3. ② prompt ကို paste လုပ်ပြီး generate လုပ်ပါ။ Generate မနှိပ်ခင် ကုန်မယ့် Flow credit (ဥပမာ "60 credits") ကို မှတ်ထားပါ။
4. ရလဒ်ကို စစ်ပါ:
   - [ ] ပစ္စည်းက အစကနေ အဆုံးထိ တူတယ် (ပုံစံ၊ အရောင်၊ logo မပြောင်း)
   - [ ] Storyboard panel တွေရဲ့ အစဉ်အတိုင်း သွားတယ်
   - [ ] Screen ပေါ်မှာ စာ၊ စာတန်း၊ ခလုတ်၊ watermark မပါဘူး
   - [ ] စကားပြောသံ၊ music မပါဘူး (ပစ္စည်းသံ ပါရင် ရပါတယ်)
   - [ ] Storyboard ပုံကို ကူးထည့်ထားတာ မဟုတ်ဘဲ live-action video ဖြစ်တယ်
5. မကောင်းရင် **စုစုပေါင်း ၂ ကြိမ်အထိ** ပြန်ထုတ်လို့ရပါတယ်။ အဲဒါထက် ပိုလိုရင် ရပ်ပြီး ကျွန်တော့်ကို မေးပါ။
6. အကောင်းဆုံး video ကို **MP4 (720p)** နဲ့ download လုပ်ပါ။

## အဆင့် ၄ — App ထဲ ထည့်ခြင်း (လုပ်နိုင်ရင်)
1. Product page ရဲ့ **"③ Your clip from Flow"** မှာ download ဆွဲထားတဲ့ MP4 ကို ထည့်ပါ။
2. File ထည့်လို့ မရရင် ဒီအဆင့်ကို ကျော်ပြီး file ရှိတဲ့နေရာကို ကျွန်တော့်ကို ပြောပါ။
3. **"🎬 Create videos" ကို မနှိပ်ပါနဲ့။** အဲဒါကို ကျွန်တော် ကိုယ်တိုင် စစ်ပြီး နှိပ်ပါမယ်။

## လုံးဝ မလုပ်ရတာ
- Flow credit ဒါမှမဟုတ် Google One/AI plan ကို **ဝယ်တာ၊ upgrade လုပ်တာ**
- Billing၊ account၊ password၊ 2FA setting တွေကို ပြင်တာ (login မေးရင် ရပ်ပြီး ကျွန်တော့်ကို ခေါ်ပါ)
- Video ဒါမှမဟုတ် ပုံကို share လုပ်တာ၊ public လုပ်တာ၊ social media ပေါ် တင်တာ
- ကျွန်တော့် app ထဲမှာ ပိုက်ဆံကုန်တဲ့ ခလုတ်တွေ နှိပ်တာ ("Create videos", "AI video", "Make scene images")
- အထက်က ကန့်သတ်ချက် (storyboard ၃ ကြိမ်၊ video ၂ ကြိမ်) ထက် ပိုထုတ်တာ

## မသေချာရင်
Flow ရဲ့ menu နာမည်တွေ ကွဲနေရင် အနီးစပ်ဆုံး ရွေးချယ်မှုကို သုံးပါ။ ဒါပေမဲ့ ကုန်ကျစရိတ် ပိုများမယ့် ရွေးချယ်မှု ဒါမှမဟုတ် ဘာလုပ်ရမလဲ မသေချာရင် ရပ်ပြီး ကျွန်တော့်ကို မေးပါ။
